# Скорочтение за 14 дней

Комплект для самостоятельного обучения: интерактивное веб-приложение (PWA), Word-пособие и презентация-тренажёр.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Интерактивный курс: 14 уроков, тренажёры, XP, ранги, серия дней, боссы, график прогресса. |
| `manifest.webmanifest` | Паспорт приложения: имя, иконки, цвета, запуск без адресной строки. |
| `service-worker.js` | Офлайн-режим: кэширует уроки, тексты и графику после первого открытия. |
| `Скорочтение_пособие.docx` | 47 страниц: теория, 14 схем, печатные приложения, тексты для замеров, ключи. |
| `Скорочтение_презентация.pptx` | 26 слайдов: ключевые мысли дня + тренировка на слайде, ответы в заметках. |

## Быстрый старт

**Просто посмотреть:** откройте `index.html` двойным щелчком. Курс работает, но установка на телефон и офлайн-кэш в этом режиме недоступны — браузер не включает service worker для файлов с диска.

**Полноценное приложение:** запустите локальный сервер из папки курса.

```bash
python -m http.server 8123
```

Затем откройте `http://localhost:8123`. Здесь уже работают установка, офлайн-режим и обновления.

## Установка на телефон

- **Android (Chrome):** меню ⋮ → «Установить приложение» (или баннер внизу страницы).
- **iPhone/iPad (Safari):** «Поделиться» → «На экран „Домой“» → «Добавить». Через 7 секунд после открытия курс сам покажет подсказку.
- **Компьютер (Chrome/Edge):** значок установки в адресной строке.

После установки курс открывается с домашнего экрана без адресной строки и работает без интернета.

> Важно: установка и офлайн-режим требуют **HTTPS или localhost**. Открытие по локальной сети вида `http://192.168.x.x:8123` с телефона не даст установку — нужен HTTPS-хостинг.

## Публикация

Папку можно выложить на любой статический хостинг без сборки: GitHub Pages, Netlify Drop, Cloudflare Pages, обычный сервер с HTTPS. Загружайте всё содержимое папки, включая `manifest.webmanifest` и `service-worker.js`.

## Обновление версии

При изменении файлов поднимите `VERSION` в `service-worker.js` (например, `sr14-v2`). Пользователи получат уведомление «Доступна новая версия»; прогресс при обновлении сохраняется.

## Прогресс

Прогресс хранится локально в браузере (localStorage) и привязан к устройству. В разделе «Прогресс» есть экспорт в JSON. Синхронизация между устройствами — следующий этап; для неё понадобится аккаунт и серверная часть.

## Печать

Приложения Word-пособия рассчитаны на печать:

- **А. Таблицы Шульте 5×5** — 6 таблиц, по две на страницу.
- **Б. Клиновидные таблицы** — 3 блока.
- **В. Дневник тренировок** — 14 строк + личные рекорды.
- **Г. Трекер 14 дней** и план на 30 дней.
- **Д. Тексты для замеров** — 4 текста с полями для времени и понимания.
- **Е. Ключи к проверкам.**
- **Ж. Шпаргалка** — техники, дозировки, мифы, словарь.

## Методическая основа

Курс собран вокруг факторов, которые действительно влияют на скорость чтения:

- число фиксаций и захват слов за одну фиксацию;
- возвратные движения глаз (регрессии);
- внутреннее проговаривание и управление им по задаче;
- выборочное чтение: сканирование и просмотр;
- вопросы до чтения и стратегия SQ3R;
- внешний темп (метроном, пейсинг, RSVP, упражнение 3-2-1);
- проверка понимания, припоминание, интервальное повторение, заметки Корнелла;
- управление вниманием и средой.

## Честные ограничения

- Курс не обещает 1000+ слов в минуту с полным пониманием: воспроизводимых подтверждений этому нет.
- Реалистичный результат 2–3 недель — рост в 1,5–2 раза при понимании не ниже 70%.
- Гимнастика для глаз, «активация полушарий» и фоточтение не используются: это не работает.
- Скорость засчитывается только вместе с пониманием: эффективная скорость = слов/мин × понимание ÷ 100.
